PHP PDO is a database access layer that provides a uniform interface for working with databases

PDO allows for working with any database that has a PDO driver available
it relies on database-specific drivers
such as PDO_MYSQL, PDO_PGSQL, PDO_OCI for oracle database

Therefore, to use PDO for a specific database, you need to have a corresponding database driver available.


SQL to grant priviliges of a database (all tables) to a user:
GRANT ALL PRIVILIGES ON <databasename>.<tables> ON 'user'@'host';
example:
GRANT ALL PRIVILIGES ON chat_app_db.* ON 'project_tester'@'localhost';
